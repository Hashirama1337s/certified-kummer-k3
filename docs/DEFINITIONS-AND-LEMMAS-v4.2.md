### 1.2 The Green function S
For any split parameter eta > 0 put
  S_eta(x) = sum_{l in L} exp(-eta |x-l|^2)/|x-l|^2 + (1/V) sum_{k in L*, k != 0} exp(-pi^2 |k|^2/eta)/|k|^2 * cos(2 pi k.x),
L* = dual lattice = 2 D4 = {k in (2Z)^4 : (k0+k1+k2+k3)/2 even}, minimal |k|^2 = 8.
**Lemma S (PROVED).** (i) Both sums converge absolutely with all derivatives, locally uniformly on R^4 minus L. (ii) S_eta - pi^2/(V eta) does not depend on eta; call it S (mean zero over a cell). (iii) S is L-periodic, W-invariant (in particular even), real-analytic off L, and S - 1/|x-l|^2 extends analytically across l. (iv) sum_i d_i dbar_i S = pi^2/V off L (equivalently the real Laplacian of S is 4 pi^2/V).
Proof. 1/s = integral_0^inf exp(-t s) dt; the part t >= eta gives exp(-eta s)/s. (iv): for x != 0, Laplacian of exp(-t|x|^2) equals -4 d/dt [t^2 exp(-t|x|^2)], so the Laplacian of exp(-eta|x|^2)/|x|^2 is 4 eta^2 exp(-eta|x|^2); summing over L and using Poisson summation for Gaussians (sum_l exp(-eta|x-l|^2) = (1/V)(pi/eta)^2 sum_k exp(-pi^2|k|^2/eta) exp(2 pi i k.x)) gives (4 pi^2/V) sum_k exp(-pi^2|k|^2/eta) cos(2 pi k.x); the reciprocal sum contributes minus the same without k = 0. (ii): d/d eta of the real-space sum is -sum_l exp(-eta|x-l|^2), of the reciprocal sum (pi^2/(V eta^2)) sum_{k != 0} exp(-pi^2|k|^2/eta) cos(2 pi k.x); by the same Poisson identity the total is -pi^2/(V eta^2). (iii): termwise; the term l of the real-space sum minus 1/|x-l|^2 is v(|x-l|^2), v(s) = (exp(-eta s) - 1)/s entire. W-invariance: W preserves L and L*. QED
The additive constant of S never matters (only d dbar S is used). CHECK: k1.py control C3 (trace = pi^2/V); check_misc.py: |trace d dbar psi_1| <= 1.8e-8.
Notation: S_reg(z) := S(z) - 1/|z|^2 (analytic on |z| < 1/2).

### 1.3 Eguchi-Hanson and the remainder kernel R
eps := a^4. f(s) := sqrt(s^2 + eps). phi_a(s) := f + a^2 log s - a^2 log(a^2 + f), so phi_a' = f/s (PROVED by differentiation). Scaling: phi_a(s) = a^2 phi_1(s/a^2) + const.
g0 := d dbar phi_a(|z|^2), i.e. g0_{i jbar} = (f/s) delta_ij + (phi_a'') zbar_i z_j. Eigenvalues: A := s/f on the radial complex line C z, B := f/s on its orthogonal complement; det g0 = 1.
R_a(s) := -integral_s^inf (f/t - 1 - eps/(2t^2)) dt. With u = eps/s^2, w = sqrt(1+u):
  R_a' = w - 1 - u/2 = -u^2/(2(1+w)^2),   (s R_a')' = 1/w - 1 + u/2 = (w-1)^2 (w+2)/(2w).
For u <= 1: R_a' = sum_{k>=2} b_k u^k, (s R_a')' = sum_{k>=2} (1-2k) b_k u^k, b_k = binom(1/2, k) (b_2 = -1/8, b_3 = 1/16, b_4 = -5/128). Both series alternate with decreasing terms, so every partial sum errs by at most the first omitted term (PROVED: |b_{k+1}/b_k| = (2k-1)/(2k+2) < 1, |(2k+1) b_{k+1}/((2k-1) b_k)| = (2k+1)/(2k+2) < 1, u <= 1).
The Hermitian matrix d dbar [R_a(|xi|^2)] has eigenvalue (s R_a')' on C xi and R_a' on the orthogonal line (s = |xi|^2).

## 2. Lemma A: analytic continuation and explicit Taylor bounds

Lie norm on C^4: Lie(y)^2 := |y|^2 + sqrt(|y|^4 - |y.y|^2) (y.y bilinear). Facts (PROVED, elementary): Lie(t y) = |t| Lie(y); Lie(x) = |x| for real x and for y = e^{i theta} x; Lie(y) <= sqrt 2 |y|; for y = xi + i zeta, Lie(y)^2 = |xi|^2 + |zeta|^2 + 2 sqrt(|xi|^2 |zeta|^2 - (xi.zeta)^2) <= (|xi| + |zeta|)^2.
**Lie is a norm (Fix 5, PROVED).** For y = xi + i zeta (xi, zeta in R^4) let A(y) be the real 4x2 matrix [xi zeta], with singular values s1 >= s2 >= 0. Then Lie(y) = s1 + s2 = ||A(y)||_* (nuclear norm). Proof: |y|^2 = |xi|^2 + |zeta|^2 = tr(A^T A) = s1^2 + s2^2; y.y = |xi|^2 - |zeta|^2 + 2i xi.zeta, so |y|^4 - |y.y|^2 = 4(|xi|^2 |zeta|^2 - (xi.zeta)^2) = 4 det(A^T A) = 4 s1^2 s2^2; hence Lie(y)^2 = s1^2 + s2^2 + 2 s1 s2. The nuclear norm is a norm: with the SVD A = sum s_i u_i v_i^T, for every real 4x2 matrix B with operator norm <= 1, tr(B^T A) = sum s_i u_i^T B v_i <= s1 + s2, with equality for B = sum u_i v_i^T; so ||A||_* = max_{||B||_op <= 1} tr(B^T A) is a supremum of linear functionals, hence subadditive. y -> A(y) is R-linear and injective, so Lie satisfies the triangle inequality on C^4. QED
